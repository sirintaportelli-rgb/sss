# 🏙️ Super City

**Build a city. Learn GCSE Maths.**

A solo city-builder game where every construction decision requires GCSE-level STEM problem-solving.

## Getting Started

```bash
npm install
npm start
```

Opens at http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Go to vercel.com → New Project → Import repo
3. Vercel auto-detects Create React App — click Deploy
4. Live at your-project.vercel.app

## Project Structure

- `src/App.js` — Entry wrapper
- `src/STEMCityApp.jsx` — Connects Creator → Terrain
- `src/STEMCityCreator.jsx` — City parameter selection
- `src/STEMCityTerrain.jsx` — Main gameplay screen
